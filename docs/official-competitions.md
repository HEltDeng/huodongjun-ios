# 官方赛事接入与核验

日期：2026-11-01。版本：0.4.0。

## 行为

底部导航现在为「发现 / 活动 / 赛事 / 消息 / 我的」。赛事是独立的公开信息栏目，不依赖校园身份，也不写入校园活动、报名、群聊或综测记录。发布活动在发现页右上角、活动页右上角保留。

赛事入口仅展示中国地区，默认中国全部赛事，提供北京、上海、长沙等城市及该地区线上赛事、赛场 / 月历、关键词、状态和当前赛场收藏筛选。月历显示当前已载入赛事的跨月赛程及开始 / 结束节点。详情展示起止日期、实时红绿时间条、主办方、地点、奖金、参赛团队和来源提供的报名状态。收藏可再次点击取消，并保存在本机。报名打开原赛事平台；不自动填写、提交或创建活动君报名记录。

## 数据路径

- `CompetitionDomain.swift`：独立赛事类型、日期规则、公开页面解析和来源 URL。
- `CompetitionStore.swift`：URLSession 网络请求、缓存、收藏、地区切换的请求代次和取消处理、每批最多 4 个详情请求。
- `CompetitionsView.swift`：原生赛场、日历、详情、SFSafariViewController 和次级来源说明。
- `CompetitionTests.swift`：14 项规则、解析、缓存与隔离测试。

默认读取 `https://competehub.dev/zh/regions/China/All`，城市请求固定使用 `/zh/regions/China/{city}`，再读取其中赛事的公开详情页。列表请求和响应需匹配中国及指定城市；解析、缓存和分页均拒绝全球或海外列表。城市元数据直接从中国页的 `cities` 读取，无需全球首页。解析 HTML 内 `self.__next_f.push` 携带的 JSON，拼接分块，按 UTF-8 字节长度跳过长文本帧后递归提取事实数据，支持描述与下一条记录之间没有换行的页面，不执行网页脚本，不调用私有接口。原平台跳转仅接受无用户凭据的 HTTPS URL。

应用不打包源站海报、全文介绍、网页代码或此次调试的 HTML；公开页面样本和构建日志仅位于忽略的 `.build/competitions/`。缓存位于 App 的 `Application Support/OfficialCompetitions/`，与校园 JSON 分开。详情可复用 6 小时缓存，主动下拉刷新强制重读。读取失败时保留缓存、显示错误或缓存时间。切换地区先切换对应缓存，旧请求不能覆盖新地区。

本次不是官方 API 或合作接入，网站结构变化可能导致解析失败。未来若获得稳定的授权接口，可替换 `CompetitionClient`，保留原生视图和规则。未部署后端或全量后台同步服务。

## 时间语义

赛事状态按当前时间计算：未开始、进行中、已结束、时间待公布。进度夹在 0–100%，红色为已过去、绿色为剩余；未知或无效日期不生成百分比。源站只给日历日期时，按北京时间显示，结束日期包含当天，不虚构精确截止时刻。同日赛事持续一个日历日。月份重叠与节点按同一时区计算。

源站的 `signupStatus` 1 / 2 对应可前往报名，3 对应报名结束，4 对应赛事结束。仅有赛事日期不能推出报名开始日期，因此详情标记「来源未提供」，并提供完整赛制与原平台入口。

日历只覆盖当前赛场已载入的数据，不宣称是全站日历。中国赛场按源站公开结果展示；源站当前中国全部页一次提供 92 条，若未来分页则仅继续同一中国城市的下一页。源站城市结果为空时显示空状态，不补入海外赛事或示例。

## 实测

- Xcode 26.6，iPhone 17 Pro / iOS 26.5；原生构建成功。
- 51 项 XCTest 通过，含赛事 14 项与原有 37 项。
- 中国全部页实际解析为 92 场和 11 个城市 / 线上入口；北京 1 场、长沙 1 场、上海 0 场，与当次源站城市页面一致。修复 5 个长文本详情的解析兼容，包括百度、华为实物组 / 算法组等。模拟器落盘核验：92 条赛事均已读取详情和起止日期，列表缓存键全部为中国地区。所有数据均直接来自中国赛场，没有构造示例赛事。
- 模拟器 URLSession 实际联网可读取赛场；默认展示中国全部赛事，城市切换与源站相符。
- 北京赛事详情显示 7 月 1 日至 11 月 15 日，11 月 1 日为进行中、还剩 14 天，进度条红绿分段。

- 报名按钮打开来源提供的 `mp.weixin.qq.com` 主办方赛事公告并成功加载，没有提交报名。

- 离线缓存、地区隔离、缺失日期、跨年月份、结束日边界、链接校验及分页由自动测试覆盖。

## 本机启动

- `scripts/open-simulator.command`：只启动已有 iPhone 17 Pro 并打开 Simulator。
- `scripts/run-ios.command`：调用上述脚本、生成工程、编译、安装、运行活动君。保留 App 用户数据，不创建新模拟器。
- 用 Xcode 打开 `ios/CampusEvents.xcodeproj`，选择 `CampusEvents` / `iPhone 17 Pro`，按 Command + R。
- Simulator 位于 `/Applications/Xcode.app/Contents/Developer/Applications/Simulator.app`；可从 Xcode → Open Developer Tool → Simulator 或 Finder 的「前往文件夹」打开。
