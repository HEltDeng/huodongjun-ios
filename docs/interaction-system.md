# 活动君 0.3.0 交互体系与验收

2026-10-26。维护现有原生 SwiftUI 工程、纸白与深绿色视觉、三张原有海报、校园 / 长沙双空间及学校隔离规则。

## 组件对应到真实操作

| 组件 | 使用位置 | 行为 |
| --- | --- | --- |
| 底部导航 | 发现、活动、消息、我的，中间发布入口 | 按压回弹、选中背景移动、从所选页签方向向外扩散的圆形遮罩；各页面保留导航状态 |
| Bottom Sheet | 空间、学校、兴趣、搜索、筛选、详情、报名、票券、编辑、群信息 | 使用系统 presentationDetents；统一 30%、60%、80%、系统全高四种尺寸，按内容选档；原生拖动与吸附、可见抓手、底部主要操作 |
| Action Sheet | 头像 / 封面 / 群图片、放弃草稿、取消个人报名、返回欢迎页 | 固定从底部出现的操作列表；独立取消；移除与放弃标红；设备有相机才显示拍照 |
| Snack Bar | 收藏、关注、全部已读、移除草稿图片 | 保存后给反馈与撤销；仅恢复该操作对应字段，不回滚整个数据快照；普通提示 4 秒，可撤销提示 8 秒，VoiceOver 下保留到手动关闭 |
| Alert Dialog | 主办方取消整场活动 | 显示活动名、受影响人数、凭证失效与不可撤销；遮罩点击、交互下滑和 Escape 不关闭；明确“取消这场活动 / 保留活动” |
| Tour | 首次进入新版、发现页问号、我的 → 设置 → 操作引导 | 三步聚光；用真实按钮布局锚点定位，完成 / 跳过状态持久化 |
| Lightbox | 海报大图、已选照片、活动群二维码 | 黑色全屏，捏合 1～5 倍、双击、鼠标滚动、底部缩放 / 复位 / 完成；原始资源不修改 |
| Inline Alert | 创建活动、资料、报名、学校验证、计分、核销、图片及讨论错误 | 紧邻相关字段或操作；字段校验随修正重新计算；不以计时器隐藏错误 |
| 完成反馈 | 发布、保存修改、报名、资料、兴趣、验证通过、核销、通知、计分保存 | 先执行实际写入，成功后收缩为圆形、绘制对勾、粒子与触觉反馈；失败保留原按钮与错误；处理中防重复触发 |
| 勾选联动 | 兴趣多选 | 卡片选中、进度环、数字和背景同步变化；保存后影响现有推荐规则 |
| 叠卡展开 | 活动页各列表有内容时 | 最多三张叠放；展开全部、分层回弹、按顺序微小延迟；折叠背面卡不可误点 |
| 吸附卡 + 时间线 | 首页横向推荐、活动页日程聚焦 | 原生 viewAligned 吸附；日程上下滑动停止后绘制侧边时间线 |
| 惯性滚轮 | 活动开始、结束、截止时间，以及选填生日 | 底部原生 wheel DatePicker，点确认才写回草稿，取消不改变原值 |

百分比是本应用的设计尺寸约定，不表述为所有平台或厂商强制标准。`.large` 由 iOS 管理系统可用全高与安全区域，不能用硬编码屏幕像素替代。

减少动态效果时，关闭圆形扩散、弹跳、粒子、卡片缩放等非必要运动，保留状态反馈。系统日期、相册、分享和日历由原生控件管理。

## 本次验证

- Xcode 26.6 / iOS 26.5 / 原有 iPhone 17 Pro 模拟器；原生构建成功。
- 37 项 XCTest 通过，包含原有 28 项，以及新增 9 项：独立字段错误修正、时间 / 范围 / 名额 / HTTPS 校验、分值精度、收藏撤销持久化与不覆盖其他编辑、取消收藏恢复、关注撤销、过期提示不清除新提示、按空间撤销全部已读、旧版本引导字段兼容。
- 实际操作：首页双层底部入口、兴趣勾选数量联动与保存、筛选面板 60% / 80% / 30% 切换、收起状态底部按钮、收藏撤销、灯箱显示与 200% 放大、发布表单空值报错与逐字段消除、时间滚轮点选与写回、临时活动预览及发布、完成按钮圆形状态、主办方取消弹窗、点击遮罩 / Escape 保持阻断、叠卡展开、头像底部动作面板、相册选择器打开与取消返回。
- 发现并修复：导航栏覆盖首页快捷入口、撤销条覆盖报名按钮、聚光定位偏移、图片首次布局尺寸为空、首页海报比例使标题不易看到；iOS 26.5 的 confirmationDialog 会显示为锚点浮窗，已用统一的底部动作列表替代，确保独立取消始终可见。
- 模拟器输入工具的拖动 / 滚轮手势不稳定；分档通过系统抓手的可访问操作验证，日期通过点击滚轮刻度验证。真实手指的惯性、阻尼、捏合、吸附手感和触觉强度仍需真机验收；未声称测量了帧率或覆盖所有设备 / 字体尺寸。
- 取消整场活动只验证确认防护与“保留活动”，未取消原有活动。相机实拍、系统相册授权、远程推送与学校认证不在本轮模拟器验收范围。

截图集中保存于 `docs/screenshots/v0.3/`（Git 忽略）；构建和测试日志在 `.build/InteractionQA/`。临时验收活动和为验证叠卡添加的收藏在验收结束后清理；保留当前用户选择的空间以及原有业务记录。

## 范围

此版本仍是本机体验版。UI 的保存、报名、核销、通知及计分写入本机状态；没有新增远程后端、真实学校认证、APNs 或教师生产权限。当前取消个人报名会影响候补提升及入场凭证，继续使用明确确认，不提供可能复活失效凭证的简单撤销。
