# 活动君

从长沙理工大学起步、包含校园与长沙两个独立空间的原生 iOS 活动应用。首期以 Luma 的活动产品流程为参考，覆盖活动发现、发布、报名、活动群、票券与主办方管理，并预留学校身份与综测计分功能。

## 当前交付（2026-10-26）

- 原生 SwiftUI 应用，最低 iOS 18；已在 Xcode 26.6、iPhone 17 Pro / iOS 26.5 模拟器编译安装。
- 本地 Git 分支 `codex/ios-campus-events`；尚未创建远程仓库。
- 当前为 **0.3.0 交互精修本机体验版**：操作有实际状态变化，数据以 JSON 原子写入应用沙盒，重启后保留。
- 根据用户最新决定，停止安卓参考路线；已删除此次新增的 `Luma_Reference_Play_API_36_1` AVD、专用 Google Play 系统镜像和启动脚本，保留原有 `Pixel_8_API_36_1`。
- 原版 Luma 未完成逐页实机核查。本版本不能被表述为已验证的完整 1:1 复刻；公开截图只作为视觉参考。

## 运行

打开 `ios/CampusEvents.xcodeproj`，选择 `CampusEvents` scheme 和 iPhone 模拟器运行。无需第三方包。

也可在当前已启动的模拟器上执行：

```sh
./scripts/run-ios.command
```

脚本默认使用本机已有的 `DB71B0C2-FF9A-4D52-9B10-A99E1558FBE9` 模拟器；可将其他已启动模拟器的 UDID 作为第一个参数。脚本只生成工程、构建、安装和启动本应用，不创建模拟器，不重置设备或用户数据。

## 双空间体验入口

- 发现页顶部切换「校园 / 长沙」，校园标题下选择学校。未验证的学校会先打开独立验证页。
- 「发现 → 兴趣」或「我的 → 兴趣偏好」修改兴趣；「我的 → 推荐提醒」设置两种空间的提醒和生成本机精选。
- 底部中央「+」创建活动，先选空间，再设置开放学校和标签；预览后确认发布。发布后不可修改空间或开放学校，避免已有报名和讨论越界。
- 已有本机数据自动迁移，原活动、报名、收藏和资料保留；旧学号不自动变为已认证身份。

界面沿用第一版的纸白背景、深绿主色和大海报，新增滑动空间选中效果、弹簧按压、兴趣选中反馈，并响应系统“减弱动态效果”。

学校验证按钮明确标记为本机演示，不能用于真实身份审核。推荐排序与站内精选可直接体验；本地通知需主动授权，仅根据当前设备的活动安排下一次每日/每周精选。远程新活动推送仍需服务端和 APNs。

## 后续集成

当前没有运行远程后端。学校身份认证、真正的教师/主办方权限、跨设备活动和聊天、签名票券、服务端并发名额控制、正式综测流水与撤销审计、推送、真实邀请链接、Apple Wallet 和支付尚未接入。

本机管理预览位于「我的 → 本机管理预览」，仅用于验证计分流程，不能代替正式教师后台。示例身份、活动和综测均不代表学校真实数据。
