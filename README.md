# 活动君

从长沙理工大学起步、包含校园与长沙两个独立空间的原生 iOS 活动应用。首期以 Luma 的活动产品流程为参考，覆盖活动发现、发布、报名、活动群、票券与主办方管理，并预留学校身份与综测计分功能。

## 当前交付（2026-11-01）

- 原生 SwiftUI 应用，最低 iOS 18；已在 Xcode 26.6、iPhone 17 Pro / iOS 26.5 模拟器编译安装。
- 本地 Git 分支 `codex/ios-campus-events`；对应私有仓库 [HEltDeng/huodongjun-ios](https://github.com/HEltDeng/huodongjun-ios)，远端主分支为 `main`。
- 当前为 **0.4.0 官方赛事体验版**：操作有实际状态变化，数据以 JSON 原子写入应用沙盒，重启后保留。
- 根据用户最新决定，停止安卓参考路线；已删除此次新增的 `Luma_Reference_Play_API_36_1` AVD、专用 Google Play 系统镜像和启动脚本，保留原有 `Pixel_8_API_36_1`。
- 原版 Luma 未完成逐页实机核查。本版本不能被表述为已验证的完整 1:1 复刻；公开截图只作为视觉参考。

## 运行

打开 `ios/CampusEvents.xcodeproj`，选择 `CampusEvents` scheme 和 iPhone 模拟器运行。无需第三方包。

也可在 Finder 中双击 `scripts/run-ios.command`，或在项目目录执行：

```sh
./scripts/run-ios.command
```

脚本默认启动本机已有的 iPhone 17 Pro / iOS 26.5（`DB71B0C2-FF9A-4D52-9B10-A99E1558FBE9`），随后生成工程、构建、安装和启动本应用。可将其他已有模拟器的 UDID 作为第一个参数；不创建模拟器，不重置设备或用户数据。

只打开模拟器可双击 `scripts/open-simulator.command`。模拟器的应用名称为 **Simulator（模拟器）**，位于 `/Applications/Xcode.app/Contents/Developer/Applications/Simulator.app`。在 Finder 按 `Shift + Command + G` 输入该路径，或从 Xcode 菜单 `Xcode → Open Developer Tool → Simulator` 打开。Simulator 运行已安装的 App；编辑和构建项目需用 Xcode 打开 `ios/CampusEvents.xcodeproj`，顶部选择 `CampusEvents` 和 `iPhone 17 Pro` 后按 `Command + R`。

## 官方赛事

- 底部「赛事」为独立栏目，不受校园认证和校园 / 长沙活动空间限制。
- 原生赛场列表只接入 CompeteHub 的中国赛场，默认中国全部赛事；提供北京、上海、长沙等城市及该地区线上赛事。城市入口从中国赛场读取，首页、缓存和分页都不回退到全球或海外列表。
- 原生月份日历，绿色标记开始、红色标记结束；选择日期查看节点，切换月份查看跨月赛程。日历覆盖当前赛场已载入的赛事，可加载更多。
- 详情显示主办方、平台、地点、奖金、参赛团队、起止日期与报名状态。时间条红色表示已过去、绿色表示剩余，按当前时间重算。
- 报名在系统内置浏览器打开原平台，完整赛制可回到来源页面；不代提交报名。源站未提供独立报名开始日期时如实标记。
- 下拉刷新，列表及详情缓存与校园数据独立；失败时保留旧数据、显示缓存 / 错误状态，可重试。收藏本机持久化。

当前采用公开 HTML 中的数据适配，没有官方 API 或合作授权；网页结构变更可能影响读取。未打包源站图片或全文介绍。数据来源、日期口径、缓存范围说明集中于「赛事右上角 → 来源与说明」和「我的 → 设置 → 服务说明与隐私 → 官方赛事」。实现与核验见 [官方赛事接入](docs/official-competitions.md)。

## 双空间体验入口

- 发现页顶部切换「校园 / 长沙」，校园标题下选择学校。未验证的学校会先打开独立验证页。
- 「发现 → 兴趣」或「我的 → 兴趣偏好」修改兴趣；「我的 → 推荐提醒」设置两种空间的提醒和生成本机精选。
- 发现页右上角或活动页「+」创建活动，先选空间，再设置开放学校和标签；预览后确认发布。发布后不可修改空间或开放学校，避免已有报名和讨论越界。
- 已有本机数据自动迁移，原活动、报名、收藏和资料保留；旧学号不自动变为已认证身份。

界面沿用第一版的纸白背景、深绿主色和大海报，新增滑动空间选中效果、弹簧按压、兴趣选中反馈，并响应系统“减弱动态效果”。

学校验证按钮明确标记为本机演示，不能用于真实身份审核。推荐排序与站内精选可直接体验；本地通知需主动授权，仅根据当前设备的活动安排下一次每日/每周精选。远程新活动推送仍需服务端和 APNs。
