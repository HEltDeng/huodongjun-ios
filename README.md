# 活动君

面向长沙理工大学的原生 iOS 校园活动应用。首期以 Luma 的活动产品流程为参考，覆盖活动发现、发布、报名、活动群、票券与主办方管理，并预留学校身份与综测计分功能。

## 当前交付（2026-10-23）

- 原生 SwiftUI 应用，最低 iOS 18；已在 Xcode 26.6、iPhone 17 Pro / iOS 26.5 模拟器编译安装。
- 本地 Git 分支 `codex/ios-campus-events`；尚未创建远程仓库。
- 当前为 **0.1.0 本机体验版**：操作有实际状态变化，数据以 JSON 原子写入应用沙盒，重启后保留。
- 根据用户最新决定，停止安卓参考路线；已删除此次新增的 `Luma_Reference_Play_API_36_1` AVD、专用 Google Play 系统镜像和启动脚本，保留原有 `Pixel_8_API_36_1`。
- 原版 Luma 未完成逐页实机核查。本版本不能被表述为已验证的完整 1:1 复刻；公开截图只作为视觉参考。

## 运行

打开 `ios/CampusEvents.xcodeproj`，选择 `CampusEvents` scheme 和 iPhone 模拟器运行。无需第三方包。

也可在当前已启动的模拟器上执行：

```sh
./scripts/run-ios.command
```

脚本默认使用本机已有的 `DB71B0C2-FF9A-4D52-9B10-A99E1558FBE9` 模拟器；可将其他已启动模拟器的 UDID 作为第一个参数。脚本只生成工程、构建、安装和启动本应用，不创建模拟器，不重置设备或用户数据。

## 可体验功能

| 范围 | 当前实现 |
| --- | --- |
| 首次进入 | 欢迎页、手动勾选服务说明、本机浏览、个人资料和校园身份；生日为选填 |
| 发现 | 海报推荐、活动列表、搜索、活动分类、校区和剩余名额筛选 |
| 活动详情 | 海报、主办方、时间地点、介绍、活动安排、人数、综测规则、收藏、系统分享和添加日历 |
| 报名 | 姓名/学号/学院、确认、审核中、候补、取消、报名成功二维码票券 |
| 发布 | 封面选择/上传、内容、时间地点、人数上限、审核、候补、安排、活动群、编辑 |
| 活动群 | 图片上传、放大预览、保存图片、HTTPS 群链接、二维码链接识别；按报名状态控制查看 |
| 我的活动 | 即将参加、已结束、我主办的、收藏、入场凭证 |
| 主办方 | 编辑、邀请分享、报名名单、审核、手动核销、相机/图片扫码入口、本机通知、取消活动 |
| 消息 | 本机通知、已读状态、参与活动的本机讨论记录 |
| 个人中心 | 头像和资料、收藏、组织关注、主办方工作台、通知权限入口、服务说明 |
| 综测预览 | 分值、自动/审核模式、签到时保存分值、重复核销不重复计分、审核记录、个人汇总 |

微信/QQ 一键打开取决于设备是否安装对应应用及是否有平台支持的有效链接。普通群二维码不能保证直接跳入群；支持保存二维码后到对应应用识别。iOS 模拟器不能验证真实相机扫描，可用图片或手动核销码体验。

## 验证

XCTest 覆盖海报打包、报名幂等性、人数/候补/审核、学校和身份边界、截止时间、取消及重新报名凭证、核销权限与时间窗口、重复核销、计分快照、持久化、发布编辑及群数据、活动所有权、旧详情报名状态。

```sh
xcodebuild -project ios/CampusEvents.xcodeproj -scheme CampusEvents -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -derivedDataPath .build ONLY_ACTIVE_ARCH=YES CODE_SIGNING_ALLOWED=NO test
```

交互检查和限制见 `docs/design-qa.md`。Xcode 工程可通过 `python3 scripts/generate_xcode_project.py` 重新生成；新增源文件后先运行此命令。

## 目录

- `ios/CampusEvents/`：SwiftUI 页面、业务规则、数据存储。
- `ios/CampusEventsTests/`：核心规则与持久化测试。
- `ios/CampusEvents/Assets.xcassets/`：图标和三张原创海报。
- `ios/CampusEvents/Resources/`：原创海报源文件；不是 Luma 的素材。
- `scripts/`：工程生成、图标生成、模拟器运行脚本。
- `docs/interaction-audit.md`：对标证据与尚未核实的交互。
